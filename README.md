How To Play

To play all you have to do is watch the ai’s slowly run and after each generation runs it showcases what we have for its run time then the pause at the end is the next generation being calculated.

How does it work?

Basically at the start the class neural network is basically the Brian of the AI’s, it has a setup function which generates the brain. And it also has a mutate function which is used to mutate the brain so it’s not the same. And it also lastly has a calculate function which is used to figure out what this brain would do in situations given its inputs.

The setup function just creates the original brains for the taggers and runners in a list.
And the enhancement loop is just run matches between the best runners and taggers of each generation evolve the species and display’s the best agents of the last generation.
